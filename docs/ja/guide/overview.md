# RMC 法と RMC_POT

Reverse Monte Carlo（RMC）法は、散乱実験などで得られたデータに整合する三次元原子配置を構築する手法です。原子配置から計算した散乱量と測定値との差を評価し、原子位置の試行変更を反復します。RMC は原子間相互作用から構造を予測する通常の分子動力学法とは異なり、測定データとの一致を主要な評価基準とします。

## 原子配置から散乱量を計算する

RMC_POT の初期構造は、原子数、原子種、シミュレーションセルの大きさと原子座標から構成されます。RMC の原子種の順序は `.cfg` ファイルの記載順で決まり、部分相関の順序にも反映されます。原子種が $n$ 種なら、独立な部分相関の数は $n(n+1)/2$ です。例えば3種類では、1–1、1–2、1–3、2–2、2–3、3–3の順になります。

原子間距離をビン幅 $\Delta r$ のヒストグラムに集計し、規格化して部分二体分布関数 $g_{ij}(r)$ を求めます。さらにフーリエ変換によって部分構造因子を計算し、測定に対応する重みで合成して全散乱量を得ます。中性子の場合、重みは各元素の組成と散乱長に依存します。一方、X線・電子線の場合は原子散乱因子が散乱ベクトルに依存するため、部分相関の重みも一般に $Q$ または $g$ に依存します。

RMC_POT は、中性子回折の $S(Q)$、X 線回折の $F(Q)$ や $I(Q)$、電子回折の $F(g)$、EXAFS の $E(k)$ などを扱います。部分二体分布関数 $g_{ij}(r)$ 自体をフィットする機能もありますが、公式マニュアルでは、実験回折データを変換して $g(r)$ としてフィットすることは推奨していません。主として分子動力学計算から得た $g(r)$ によるポテンシャルの検証を想定しています。

## 原子移動の受理判定

各実験データセットについて、計算値と観測値の差を重み付けした $\chi^2$ を評価します。原子を試行移動させ、評価値が下がれば原則として受理します。評価値が増加する移動も、$\exp[-(\chi^2_{\mathrm{new}}-\chi^2_{\mathrm{old}})]$ に対応する確率で受理されます。この確率的受理により、単純な最小二乗最適化とは異なる配置探索を行います。

移動候補は、原子間の最小距離（hard-sphere cutoff）などの制約も受けます。初期構造に距離違反が存在する場合の扱いには特則があり、距離違反を解消または緩和する移動は、$\chi^2$ の変化だけで判定されません。移動原子数と移動幅は探索効率と受理率に影響するため、設定値とログを併せて確認します。

## 実験データと構造制約の役割

散乱データだけでは局所構造が一意に決まらない場合があります。そのため、必要に応じて原子間距離、配位数、結合角、FNC、その他の構造制約を組み合わせます。配位数制約は指定した距離範囲に存在する近接原子数を、結合角制約は三原子の角度分布を評価します。FNC（Fixed Neighbour Constraint）は、指定した原子対の距離を許容範囲に維持し、分子の結合関係を保つために利用できます。

制約は構造の曖昧さを減らしますが、設定した条件が必ずしも実験から直接導かれるとは限りません。制約を強く設定した結果と、測定データへの一致度は区別して評価する必要があります。設定方法と入力形式については [構造制約](constraints.md) を参照してください。

## RMC_POT と RMC_UTIL の担当範囲

RMC_POT は C++ で実装された構造モデル生成・フィッティングの計算エンジンです。RMC_UTIL はそのエンジンを置き換えるものではなく、Python から入力条件の編集、実行管理、結果ファイルの解析を扱う補助ライブラリです。

ソースコード上では、`RmcPot` が計算実行と関連オブジェクトの管理を担い、`RmcPotDat` が `.dat` の取り扱いを担います。`RmcPotLog` はログ処理に用いられます。これらは独立した機能を持ちますが、同じ `Config` を共有して計算対象の基底名などを扱う構成です。具体的な API は [API リファレンス](../api/index.md) と [README に基づく利用マニュアル](readme_manual.md) を参照してください。

RMC_POT の計算を始めるには、初期原子配置、計算条件、および使用する実験データを準備します。各ファイルの役割は [入力ファイル](input.md)、計算後の確認項目は [出力ファイル](output.md) にまとめています。

詳しい理論は [RMC 法の解説](../reference/rmc_theory_explained.md) を参照してください。
