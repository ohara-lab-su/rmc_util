# 入力ファイル

RMC_POT の入力は、原子配置、実行条件、実験データ、および必要に応じた構造制約・ポテンシャルから構成されます。RMC_UTIL はこれらのファイルの一部を Python から読み書き・編集するためのライブラリです。**RMC_POT 本体の入力仕様**と**RMC_UTIL の操作 API**を区別してください。

## ファイルの役割

| ファイル | 役割 | RMC_UTIL の関連 API |
| --- | --- | --- |
| `*.cfg` | 初期原子配置、原子種別の個数、シミュレーションセル | `RmcPot`、`util.cfg2poscar`、`util.poscar2cfg` |
| `*.dat` | 計算条件、実験データ指定、制約、出力制御 | `RmcPotDat`、`RmcPotDatFixed`、`RmcPotDatFree` |
| 実験データファイル | 回折・EXAFS などの測定値と必要な係数 | `*.dat` 内で参照 |
| `*.fnc` | 原子間の固定近接関係と許容距離 | `RmcPotDatFnc` |
| `*.top` | 分子トポロジー・相互作用の記述 | `RmcPotDatTop` |

ファイルの構文、ヘッダー、列の定義は [RMC_POT 入力ファイル詳説](../reference/rmcpot_input_explained.md) にまとめています。RMC_POT user guide 2023.1 の II.C–II.I に対応します。

## 初期配置 `*.cfg`

マニュアル II.D によれば、テキスト形式の `*.cfg` は、総原子数、原子種数、セルの半辺長、各原子種の原子数をヘッダーに持ち、その後に**原子種ごとにまとめた座標**が続きます。座標は各軸で −1 から +1 の換算座標であり、距離とセルの半辺長は Å 単位です。一般的な Cartesian 座標の POSCAR と混同しないでください。

原子種の並びは部分相関関数の並びを決定します。原子種が3種類なら部分の順序は `1-1, 1-2, 1-3, 2-2, 2-3, 3-3` です。`*.dat` の部分別 cutoff や散乱係数も、この順序との整合性が必要です。

## 計算条件 `*.dat` の2形式

RMC_POT は従来の**固定形式**と、セクション・キーワードによる**自由形式**を扱います。固定形式では行の順番と項目位置が意味を持ちます。自由形式は先頭の `#002` または `#003` によって識別され、`[ GENERAL ]`、`[ EXP ]` などのセクションと `KEY = VALUE` の記述を使います。先頭のバージョン番号は単なる注記ではありません。

`#002` と `#003` は X 線散乱係数の既定動作が異なります。マニュアル II.C によれば、`#002` では係数ファイルの読込みが既定で、`#003` では化学記号を与えたうえでの係数計算が既定です。`READ-COEFFS` を使う場合も、設定と実験データの整合を確認してください。

添付ソースの `RmcPotDatFree` には、自由形式のテンプレートとして `NDENS`、`CUT-OFF`、`MAX-MOVES`、`R-SPACING`、`RUN-TIME`、`SAVE-TIME`、`TYPE`、`DATAFILE`、`POINT-RANGE`、`SIGMA` などのキーワードが記述されています。ただし、**テンプレートの値は実験・試料に共通の推奨値ではありません**。原子密度、原子種数、実験データ範囲に合わせて設定する必要があります。

## 実験データと単位

RMC_POT は中性子回折、X 線回折、電子回折、EXAFS、および部分・全二体分布関数などのデータを扱います。各データの種類、横軸、散乱係数、正規化は同一ではありません。マニュアル I.B の単位規約および II.E の実験データファイル仕様を確認してください。

複数のデータセットを使う場合、各データセットの `SIGMA` は目的関数への寄与を左右します。データの測定誤差と計算上の重み付けを区別し、単純に同じ値を流用しないでください。

## 読込み前の整合性確認

1. `*.cfg` の総原子数、原子種数、原子種ごとの個数が一致すること。
2. `*.dat` の密度またはセル寸法と `*.cfg` の幾何学的条件が矛盾しないこと。
3. 原子種の順序と、部分別 cutoff・移動幅・散乱係数の順序が一致すること。
4. 実験データの種類、範囲、係数の読込み・計算方法が一致すること。
5. `*.fnc` や `*.top` を使う場合、原子番号、分子の対応、単位系を確認すること。特に GROMACS トポロジーの距離単位 nm と RMC の Å を混同しないこと。
