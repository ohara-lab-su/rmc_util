# 出力ファイルと解析

RMC_POT は実験データへの適合度だけでなく、原子配置、部分二体分布関数、試行移動の履歴、制約に関する情報を出力します。**出力されるファイルは入力条件・実行機能・保存設定によって異なります。** RMC_UTIL には、それらの一部を読み取るモジュールがあります。

## 主なファイル

| ファイル | 主な内容 | 対応する RMC_UTIL モジュール |
| --- | --- | --- |
| `.fit` | 実験値と計算値の比較 | `rmc_pot_fit` |
| `.hst` | 計算履歴、適合度や制約項の推移 | `rmc_pot_hst` |
| `.ppcf` | 原子種対ごとの部分二体相関関数 | `rmc_pot_ppcf` |
| `.cfg` | 原子配置 | `rmc_pot`、`util.cfg2poscar`、`util.poscar2cfg` |
| `.log` など | 実行時の記録 | `rmc_pot_log` |
| `.free`、`.freer`、`.freers` | 自由形式で書き出された設定と非既定値 | `rmc_pot_dat_free` 関連 |
| `.cnc`、`.cncd` | 配位数制約の判定情報（機能・設定に依存） | RMC_POT の出力仕様を参照 |

各ファイルの列とヘッダーの定義は [出力ファイル詳説](../reference/rmcpot_output_explained.md) を参照してください。ファイル名の拡張子だけから、すべての列構成を決めつけないでください。

## `.fit` の読み方

`.fit` は計算結果と入力データの比較に用います。比較する量が中性子の $S(Q)$、X 線の $F(Q)$ または $I(Q)$、電子回折の $F(g)$、EXAFS の $E(k)$ のどれであるかを最初に確認してください。散乱係数、バックグラウンド補正、規格化の設定が異なれば、同じ曲線形状でも数値の意味が異なります。

RMC_UTIL の [`.fit` API](../api/rmc_pot_fit.md) を使う場合も、ファイル形式の解釈と実験量の物理的な解釈を区別してください。

## `.hst` と収束評価

履歴の評価では、実験データに対応する目的関数と、構造制約・ポテンシャルに対応する寄与を区別します。マニュアル I.A はデータセットごとに重み付き残差から $\chi^2$ を構成することを説明しています。したがって、異なる `SIGMA`、データ点数、制約構成で得た数値を、そのまま横並びに比較することはできません。

受理率、残差、制約の充足状況、原子配置の変化を併せて確認することが重要です。RMC_UTIL の [`.hst` API](../api/rmc_pot_hst.md) と [ログ API](../api/rmc_pot_log.md) を参照してください。

## `.ppcf` と構造解析

部分二体相関関数 $g_{ij}(r)$ は、中心原子種 $i$ の周囲に原子種 $j$ がどの距離で分布するかを表します。部分の並びは `*.cfg` に記述された原子種の順序に依存します。マニュアル I.A は RMC の内部ヒストグラムが一意な原子対を数えるため、通常のヒストグラムと計数方法が異なることも説明しています。

部分関数を比較するときは、原子種順序、距離刻み、数密度による規格化を確認してください。[`.ppcf` API](../api/rmc_pot_ppcf.md) と [RMC 理論](../reference/rmc_theory_explained.md) を参照してください。

## 再実行と設定の追跡

マニュアル II.C によれば、RMC_POT は自由形式の設定を `.free` に出力し、非既定値のみを `.freer` に記録します。スケーリング可能な sigma を使う場合は、スケーリング後の値を記録した `.freers` も生成されます。再現性を確保するため、**実行に使った入力**と**実行後に出力された設定**の双方を保存してください。

**参照**：RMC_POT user guide 2023.1, I.A, I.L, II.B–II.C。
