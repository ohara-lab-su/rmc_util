# 構造制約

RMC は実験データに整合する原子配置を探索しますが、散乱データだけで局所構造が一意に定まるとは限りません。RMC_POT は距離、配位数、結合角、分子内の近接関係などを制約として与える機能を備えています。制約は**実験データの代替**ではなく、独立した構造情報を目的関数や試行移動の可否に反映させるものです。

## ハードスフィア cutoff

原子種の組ごとに最短許容距離を指定し、非物理的な原子の重なりを抑えます。原子種数を $n$ とすると、異種原子の組を重複して数えない部分の数は $n(n+1)/2$ です。cutoff はこの部分順序に従って指定します。値は試料の化学結合や初期配置と整合させてください。

## 配位数制約と平均配位数制約

配位数制約は、中心原子種の周囲の指定距離範囲に、指定した近接原子種が何個存在するかを評価します。中心原子のうち所定の配位数を満たす割合を制約でき、複数の近接原子種を同じ制約に含めることもできます。マニュアル I.L は、同一の中心・近接原子種について異なる配位数と割合を指定する場合、サブ制約を使う構成を説明しています。

平均配位数制約は、各中心原子が個別に条件を満たす割合ではなく、対象中心原子全体の**平均配位数**を制約します。両者は異なる構造情報であり、目的に応じて選択します（マニュアル I.M）。

## 結合角分布

マニュアル I.K の結合角制約は、中心原子と2つの近接原子が作る角度の **$\cos\theta$ 分布**を対象とします。中心原子種と近接原子種の指定順序が重要です。目標分布として、指定範囲の一様分布、ガウス分布、特定角度領域の排除、ファイルから読み込む実験分布を選べます。

角度は度で指定する項目と、$\cos\theta$ 空間で幅を指定する項目があるため、同じ数値でも意味が異なります。正の制約と排除制約を併用する際は、対象角度領域の重なりに注意してください。

## Fixed Neighbour Constraint（FNC）

FNC は原子番号で定義した近接原子の組について、距離が許容範囲に入るよう分子を保持するための制約です。`*.fnc` に近接原子番号、制約種別、許容距離を記述します。マニュアル I.N には、初期配置が許容範囲を満たすことを要求するモード、初期距離に合わせて範囲を調整するモード、範囲外の距離が改善する移動を許容するモードが記載されています。

自由形式 `*.dat` の `FNC-TYPE` では `NONE`、`NORMAL`、`ADJUST`、`MOVE-IN` などの指定が使われます。RMC_UTIL 側の FNC ファイル操作は [API](../api/rmc_pot_dat_fnc.md) を参照してください。

## 高度な幾何学的制約とポテンシャル

RMC_POT には共通近接原子などの高度な幾何学的制約があり、マニュアル I.O はコンパイル時の `_ADVANCED_GEOM_CONST` オプションへの依存を明記しています。入力キーワードが存在することだけでは、使用する RMC_POT バイナリが機能を備える保証にはなりません。

また、マニュアル I.Q には GROMACS 型の相互作用や表形式の非結合ポテンシャルを用いる機能が記載されています。これらは幾何学的制約と同一の扱いではありません。特に分子内相互作用の二重計上や排除相互作用の扱いを確認してください。

## 設定と評価の注意

制約を強めれば必ず実験データへの適合が改善するわけではありません。制約の重み、距離範囲、目標割合と、実験データ側の適合度を分けて確認してください。設定構文は [入力ファイル詳説](../reference/rmcpot_input_explained.md)、原理は [RMC 法の理論](../reference/rmc_theory_explained.md)、出力の確認は [出力ファイル](output.md) を参照してください。
