# チュートリアル

RMC_UTIL を用いた計算条件の設定、構造制約の指定、結果の解析に必要な Python コード例をまとめます。RMC_POT の計算には、原子配置、実験データ、計算条件ファイルおよび RMC_POT 実行ファイルが必要です。

```{toctree}
:maxdepth: 2

readme_examples
```

## 入力ファイルを準備する

RMC_POT の計算では、`sample.cfg` のような原子配置ファイルと、同じ基底名の `sample.dat` などの計算条件を使用します。`sample` はファイルの基底名であり、実際の計算では対象に応じた名前を指定します。原子数、原子種の順序、数密度、原子間距離の cutoff、および実験データの指定を整合させます。

`.cfg` の座標形式と `.dat` の固定形式・自由形式の違いは [入力ファイル](../guide/input.md) を参照してください。RMC_POT の入力仕様は [ファイル形式リファレンス](../reference/index.md) に記載しています。

## Python から計算条件を設定する

[RMC_UTIL のコード例](readme_examples.md) には、`RmcPotDat` を使用した `.dat` の初期化、数密度、cutoff、最大移動幅、ヒストグラムのビン幅などの設定例があります。複数の設定を行った後に `write()` で保存する例では、各設定時の自動書込みを抑制しています。

数密度は原子数とセル体積に整合させ、cutoff は原子種の組合せに対応する順序で指定します。これらの値は構造モデルと実験条件に依存するため、コード例の数値をそのまま転用するのではなく、対象系に合わせて設定します。

## 構造制約を指定する

コード例には配位数制約と Qn 制約の設定が含まれます。配位数制約では中心原子種、近接原子種、距離範囲、目標配位数、割合、重みを指定します。構造制約の物理的な意味と RMC_POT 側の設定形式は [構造制約](../guide/constraints.md) を参照してください。

## 計算結果を確認する

計算終了後は、ログに記録された生成・試行・受理の回数、評価関数の変化、フィット結果および部分二体分布関数を確認します。ログの正常終了判定と、散乱データへの一致度や構造制約の充足は別の評価項目です。出力ファイルの役割は [出力ファイル](../guide/output.md)、各クラスの操作は [API リファレンス](../api/index.md) を参照してください。
