# 最初の計算を実行するまで

ここでは `rmc_util` に付属する編集用スクリプトを使用する標準的な経路を示します。数値パラメーターは材料・実験条件に依存するため、このページでは仮の値を指定しません。

## 1. 作業ディレクトリを準備する

```bash
pip install rmc-util
rmc_util install
```

`rmc.py` と `rmc_init.py` が展開されたことを確認します。既存の同名ファイルは保持されます。

## 2. 計算条件を編集する

`rmc_init.py` を開き、対象構造、入力ファイル名、RMC_POT の実行条件を対象の計算に合わせて設定します。実際の設定項目は配布された `rmc_init.py` を基準としてください（このファイルのソースは今回の提供資料に含まれていません）。

## 3. 入力ファイルを準備する

`.cfg`、`.dat`、必要に応じて FNC・topology、実験プロファイル等を準備します。`RmcPot.preprocess()` は必要な入力の存在を検査しますが、初期構造を自動生成する処理ではありません。

## 4. 実行する

```bash
python rmc.py
```

実行の流れは [実行ワークフロー](workflow.md)を、結果の取り扱いは [結果解析](analysis.md)を参照してください。

## 5. 再実行前の確認

既存の `.dat` を再利用する場合、`RmcPotDat.init(prefer_existing=True)` は既存の形式を判定します。初期値から再作成する動作とは区別してください。ログディレクトリの連番は `next_log_dir_name()` が既存のディレクトリを調べて決定します。
