# 構造制約

散乱データへの適合と同時に、化学的に妥当な局所構造を保つための制約を利用できます。制約の選択・設定は対象物質と解析目的によって異なります。

| 制約 | 目的 |
| --- | --- |
| 最短原子間距離 | 非現実的な原子間接近を抑える |
| 配位数制約 | 指定した距離範囲内の隣接原子数を制御する |
| 平均配位数制約 | 原子種間の平均配位数を制御する |
| 結合角分布制約 | 特定の角度分布を課す |
| FNC | 指定した原子対の距離範囲を保持する |
| SNC | 第二近接原子の配位に関する条件を課す |
| BVS | Bond Valence Sum に基づく条件を利用する |

FNC は `.fnc` に原子の結合関係と制約種を記述します。分子 topology やポテンシャルを利用する場合は `.top` なども関係します。設定項目や入力書式は使用する RMC_POT の版に合わせて確認してください。

*参照：RMC_POT user guide 2023.1, I.K–I.Q, II.C, II.G–II.I.*
