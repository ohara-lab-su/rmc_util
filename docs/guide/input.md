# 入力ファイル

RMC_POT の基本入力は、計算条件を指定する `.dat`、原子配置を記述する `.cfg`、およびフィッティングに使用するデータです。利用する制約・ポテンシャルに応じて追加ファイルを用意します。

| ファイル | 役割 |
| --- | --- |
| `.dat` | 計算条件、実験データの指定、制約・出力設定 |
| `.cfg` | 原子数、原子種、計算セル、原子座標 |
| 散乱・EXAFS データ | フィッティング対象の測定データ |
| `.fnc` | Fixed Neighbour Constraint の結合関係（使用する場合） |
| `.top` | 分子 topology・ポテンシャル関連情報（使用する場合） |

## `.dat` の形式

RMC_POT は固定書式（fixed format）と自由書式（free format）をサポートします。自由書式はファイル冒頭の `#002` または `#003` で識別され、`#003` は RMC_POT 2023.1 の標準的な形式です。特に X 線散乱係数の既定の取り扱いが形式によって異なります。

## `.cfg` の原子配置

原子種の順序は部分相関の順序にも影響します。座標は RMC の規約に従うため、外部形式との変換時には座標系・長さの単位・原子順序を確認してください。

詳細は [`.cfg` の説明](../reference/rmcpot_cfg_explained.md) と [入力ファイル詳説](../reference/rmcpot_input_explained.md) を参照してください。

*参照：RMC_POT user guide 2023.1, II.B–II.E.*
