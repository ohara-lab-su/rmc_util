# Output and analysis

`RmcPotLog`, `RmcPotHst`, `RmcPotFit`, and `RmcPotPpcf` cover RMC_POT log, histogram, fitted-profile, and partial pair-correlation output respectively. `RmcPot.postprocess()` also manages collection, backup, and structure conversion.

Consult the [API reference](../api/index.md) for methods and the [RMC_POT output reference](../reference/rmcpot_output_explained.md) for file-format details.
