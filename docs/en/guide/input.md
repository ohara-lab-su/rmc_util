# Input files

RMC_POT uses a structure file (`.cfg`), a parameter file (`.dat`), and experimental data. Depending on the model, FNC and topology files may also be required.

The package provides separate modules for fixed-format and free-format DAT files, FNC constraints, and topology input. Consult the corresponding [API pages](../api/index.md) and [file-format reference](../reference/index.md).

Existing DAT files can be reused; distinguish this from generating parameters from initial defaults.
