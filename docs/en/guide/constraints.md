# Structural constraints

FNC and topology input provide structural restrictions for RMC calculations. The package includes FNC and topology input modules and an `RmcPot.check_fnc_cutoff_consistency()` check comparing FNC minimum distances with DAT hard-sphere cutoffs.

Set numerical constraints according to the material and experimental model; this documentation does not prescribe universal values. See [the constraints tutorial](../tutorial/constraints.md) and [API reference](../api/index.md).
