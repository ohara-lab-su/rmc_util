# Analyzing results

After execution, use the relevant output handler:

- `RmcPotLog`: calculation logs.
- `RmcPotHst`: histogram data.
- `RmcPotFit`: fitted experimental profiles.
- `RmcPotPpcf`: partial pair-correlation functions.

Read the [source-derived API reference](../api/index.md) for available methods and the [output-format documentation](../reference/rmcpot_output_explained.md) for the meaning of the files.
